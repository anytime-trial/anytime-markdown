## レビューの観点

1. 定義したテスト範囲が実施されているか（「テスト範囲との突合」）
2. 各テストが、名前どおりのことを実際に確かめているか（「確かめること」）
3. 確認範囲を縮める変更が無いか（「要確認」「削除されたテスト」）

| <例: UI 変更の E2E> | <方針文書 §4> | — | **欠落** |
