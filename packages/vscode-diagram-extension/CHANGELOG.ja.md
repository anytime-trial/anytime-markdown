# 変更履歴

## [0.2.0] - 2026-09-22

### 追加

- 上下（左右）に揃って並んだ 2 要素をカーブで結ぶと、軸の上で直線に潰れず右回りに張り出すようにした。片端が矢印の線に限る（向きの無い線では右回り・左回りの区別が読み手に伝わらず、ただ遠回りした線に見えるため）。張り出しは端どうしの距離の 0.3 倍で、下限は札の交差軸側の 0.25 倍、上限は同じく 0.5 倍。
- ビューアに `alwaysEditing` を追加した（既定は偽なので本拡張と web-app の見た目は変わらない）。真のとき開いた時点から編集状態にし、編集・閲覧の切替と図の中の保存ボタンを出さず、宿主が保存を起こせるよう `handle.save()` を公開する。

### 変更

- 操作列を図の枠の中（左上）へ浮かせ、ミニマップを枠の右上へ寄せた。
- 系図の編集ダイアログを最初から編集状態で開き、保存の口をヘッダーの「適用」1 つへ寄せた。従来は閲覧状態から始まって鉛筆の切替を押させ、保存の口が 2 つあってどちらが本文へ効くのか押す前に読めなかった。

### 修正

- 手で引いた線を持つ図を `*.diagram.json` のカスタムエディタから保存できるようにした。webview が画面の形の端（`{ kind: 'element' }` の組）をそのままファイルの形を読む `validateDiagramDocument` へ渡していたため、手で引いた線を 1 本でも持つ図は必ず断られていた。断りは `saveFailed` として webview へ返るだけで拡張のログにも本文にも残らない。境界をファイルの形の本文（文字列）にし、webview は文字列を送り拡張は `JSON.parse` してから従来どおり検証する。
- markdown 拡張の系図フェンスで同じ理由の拒否が出ていたのを根本で直した。書き出して読み直す言い回しを `diagram-core` の `validateDiagramDraft` へ 1 か所に寄せ、フェンス・`mcp-diagram`・web-app の 3 経路とも通す。
- 張り出したカーブが図の縁で切られるのを直した。深さに上限が無いと最上段・最左列で制御点が負の座標へ回り込み、外側の `<svg>` の `overflow: hidden` で曲線の腹が切り落とされていた。
- 張り出したカーブの中点が線から浮くのを直した。この点は取っ手・添え字・別の線の取り付き先なので、弦の真ん中のままだと線から最低 36px 離れ、そこから別の線が生えていた。
- 保存中の門を図の中の保存ボタンの `disabled` から `save()` の中へ移した。`alwaysEditing` の宿主はそのボタンを出さないため門が 1 つも無く、連打した 2 本目が保存中の抑止を素通りして、保存中に動かした札が黙って元へ戻っていた。
- 保存後の土台に、検証前の下書きではなく宿主が実際に本文へ書いた図を据えるようにした。適用済みのはずの図が未保存へ戻ることがなくなる。
- 札に隠れる ＋／− を消さずに札の脇へ逃がし、枠の中の札は隙間を押しても図への操作にしないようにした。すき間の帯が線の押下を奪って線を選べなかったのも直した。
- ミニマップが横長の図で高くなるのを直した。

## [0.1.0] - 2026-09-21

- 初回リリース。`*.diagram.json` のカスタムエディタ、系図の自動配置、升目への手動配置、複数選択での
  移動、行・列の挿入と削除、箱の大きさの変更、ワークスペース横断の系図一覧、同梱の `mcp-diagram`
  MCP サーバー。
- anytime-travel の系図編集機能からの移植。React 実装は他の Anytime ビューアに合わせて vanilla DOM
  へ書き換えた。
