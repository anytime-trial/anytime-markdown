# Anytime Diagram

VS Code 用の系図エディタ。`*.diagram.json` を開くと、宣言された家族から図が組み上がる。
人物を升目へドラッグして配置を直し、同じファイルへ保存する。

## できること

- **自動配置**: 親子の連鎖から世代（列）を決める。記録するのは家族だけで、人物はそこから導かれる。
- **手で置く**: 編集中は升目にしか置けない。置ける升目だけに色が付くので、箱が別の箱の上に乗ることがない。
- **複数選択**: Shift・Ctrl（Mac は Cmd）＋押下か ☐ で選び足すと、選んだ全員が同じ升目数だけ動く。
  1 人でも置けなければ誰も動かない（選んだ並びが崩れない）。
- **行・列の増減**: 図の上端・左端の ＋ でその切れ目へ空の 1 本を入れ、人物の居ない行・列の − で詰める。
- **箱の大きさ**: 左上の箱の右辺・下辺・右下を掴むと、図の全体の箱が同じだけ変わる。
- **MCP サーバー**: 同梱の `mcp-diagram` が `read_diagram` / `write_diagram` / `set_diagram_layout`
  を提供する。エージェントから図を作り、並べ替えられる。

## ファイル形式

1 ファイルに図の全体を持つ。題名・導入文・末尾の注記・凡例・群の軸・家族の一覧・人物の注記・配置差分。
配置は **升目の番号**で持ち、px では持たない — 箱の大きさを変えても、手で置いた人物が升目から外れない。

```json
{
  "version": 1,
  "title": "例",
  "lead": "",
  "note": "",
  "legend": "実線は親子を表します。",
  "groups": [],
  "families": [
    { "parents": ["甲", "乙"], "children": ["丙"], "kind": "birth", "groups": {} }
  ],
  "annotations": {},
  "layout": { "placements": { "丙": { "column": 2, "row": 1 } } }
}
```

`kind` は `birth`（実線）・`creation`（点線）・`oath`（破線）の 3 つ。その図で何を指すかは `legend` の
一文で述べる。

## 人物・家族の編集

カスタムエディタが書き換えるのは**配置だけ**。人物と家族の増減は、テキストエディタで JSON を直すか、
MCP の `write_diagram` で行う。
